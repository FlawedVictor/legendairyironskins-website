# Legendairy Iron Transport Website

## Put this on GitHub Pages
1. Open your GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Commit the changes.
4. In GitHub: Settings → Pages → Deploy from branch → main / root.

## Important edits
- Replace `you@example.com` in `index.html` with your real contact email.
- Replace `https://formspree.io/f/your-form-id` with your Formspree form address.
- Replace the `#` social links with Discord, Twitch, and YouTube links.
- Replace `assets/homepage-mockup.png` later with your preferred hero truck artwork.
